# 게임 기획

## 핵심 경험

“같은 10초를 반복하는 게 아니라, 조금씩 더 긴 내일을 얻는 게임.”

플레이어는 멈춘 세계를 탐험하는 작은 여행자입니다. 매 루프는 같은 출발점에서 시작하지만 시간의 길이, 발견한 지름길, 플레이어의 숙련도는 누적됩니다.

## 목표와 규칙

여섯 시간 파편을 모두 모아 맵 가장 오른쪽의 출구에 닿으면 클리어합니다.

| 요소 | 규칙 | 의도 |
| --- | --- | --- |
| 첫 제한 시간 | 10초 | 짧은 시도와 빠른 재도전 |
| 시간 파편 | 하나당 다음 루프 +4초, 중복 획득 불가 | 실패해도 남는 성취 |
| 성장 | 10 → 14 → 18 → 22 → 26 → 30 → 34초 | 규칙을 읽기 쉬운 고정 증가량 |
| 현재 루프 | 파편을 먹어도 남은 시간은 늘지 않음 | 획득과 되감기의 의미 분리 |
| 기억의 문 | 접근하면 영구 개방 | 같은 길의 반복 피로 완화 |
| 지름길 이용 | 시작점에서 E, 가장 먼 열린 문으로 이동 | 출발점 리셋 규칙을 유지하면서 이동 비용 축소 |
| 실패 | 시간 초과, 낙하, 위험물 접촉 시 자동 되감기 | 목숨 제한 없이 학습 가능 |
| 수동 되감기 | R 또는 모바일 버튼 | 기다림 없이 다음 전략 시도 |
| 이전 루프의 잔상 | 직전 경로를 같은 시각에 재생, 충돌하지 않음 | 이번 시도와 이전 시도의 비교 |

시간 파편과 기억의 문은 서로 다른 역할입니다. 파편은 시도 가능한 시간을 늘리고, 문은 이미 익힌 구간을 건너뜁니다. 숙련자는 모든 시간 증가 단계를 일일이 기다리지 않고 더 적은 루프로 완주할 수 있습니다.

## 레벨 구성

| 구역 | 학습할 내용 | 배치 |
| --- | --- | --- |
| 01. 멈춘 정원 | 이동, 높이 조절 점프, 첫 획득과 실패 | 두 단 계단, 첫 파편, 짧은 구덩이, 가시, 기억의 문 |
| 02. 잊힌 수도교 | 끝에서 점프하기, 공중 경로 선택 | 끊어진 발판, 긴 낙하 구간, 움직이는 위험물, 두 번째 문 |
| 03. 새벽 관측소 | 배운 조작의 연속 사용 | 오르는 발판, 위험물 위를 지나는 길, 마지막 파편, 출구 |

하나의 연속 맵 안에서 배경 이름과 동선이 변합니다. 서버 접속이나 씬 다운로드를 기다리는 구간은 없습니다.

## 조작감

이동은 즉시 최대 속도로 바뀌지 않고 짧게 가속·감속합니다. 점프를 길게 누르면 높게, 일찍 놓으면 낮게 뜁니다. 발판 끝을 조금 지난 뒤에도 0.12초 동안 점프가 가능하고, 착지 직전 0.14초 안의 입력은 보관했다가 실행합니다.

점프, 착지, 획득, 되감기에는 캐릭터의 짧은 변형·파티클·합성음을 사용합니다. 오디오는 기본 꺼짐이며 사용자가 켜야 재생합니다.

## 화면 정보

중앙 상단에는 이번 루프의 남은 시간과 다음 루프의 길이를 따로 표시합니다. 우측에는 여섯 기억의 획득 상태가 남습니다. 획득 안내는 “다음 루프 +4초”를 명시해 즉시 회복으로 오해하지 않게 합니다.

실패는 버튼을 다시 누를 필요 없이 약 0.72초의 되감기 후 재시작합니다. 일시정지, 탭 숨김, 창 포커스 이탈 시에는 시간이 멈춥니다.

## MVP에서 검증할 질문

1. 첫 파편을 먹은 뒤 다음 루프가 길어진다는 규칙을 이해하는가?
2. 같은 출발점으로 돌아가도 진전이 있다는 느낌이 유지되는가?
3. 지름길이 반복 피로를 줄이면서 시간 성장의 의미를 해치지 않는가?
4. 터치 환경에서도 원하는 높이와 착지 위치를 조절할 수 있는가?

완주율, 첫 파편까지 걸린 시간, 구역별 낙하 위치, 포기 시점은 후속 테스트에서 확인할 항목입니다. 현재 MVP에는 외부 분석 수집을 넣지 않았습니다.

## 다음 확장 후보

추가 지역·선택형 시간 능력보다 먼저 실제 플레이 테스트로 이동 속도, 발판 폭, 파편 간격을 조정합니다. 그 뒤 잔상을 이용하는 스위치, 제한 시간을 소비하는 능력, 별도 도전 맵을 검토합니다. 현재 버전에 구현된 기능은 아닙니다.
