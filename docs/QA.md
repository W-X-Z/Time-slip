# 검증 결과

## 자동 테스트

Node.js 내장 테스트 러너: **21개 통과, 실패 0개**.

시간 상한과 중복 획득 방지, 현재 타이머 비회복, 자동·수동 되감기, 영구 파편·지름길, 일시정지, 낙하, 잠긴 출구, 최고 기록 보존, 저장 데이터 검증과 실패 대응, 가변 점프·점프 입력 유예·입력 버퍼, 안정적인 착지, 잔상 보간, 레벨 데이터, 정상 물리 기반 전체 완주를 검사했습니다.

`node scripts/route-check.mjs`는 좌표를 바꾸거나 파편을 주입하지 않습니다. 이동·점프·R·해제된 E 이동만 사용해 3개 루프에서 여섯 파편과 두 지름길을 획득하고 출구까지 도달합니다.

## 검증 환경과 범위

외부 네트워크와 브라우저 탐색이 제한된 실행 환경이라, 생성한 독립 실행 HTML 원본을 Chromium의 빈 페이지에 주입해 실행했습니다. 이미지·CSS·모듈이 모두 포함된 실제 빌드 산출물을 사용했고, 위치나 획득 상태를 변경하지 않았습니다.

이 환경의 origin에서는 localStorage가 차단되므로, 브라우저에서는 저장 실패 시 계속 플레이되는 동작을 검증했습니다. 저장 성공·복원은 저장소 어댑터의 자동 테스트로 확인했습니다. 실제 공개 주소에서 새로고침 후 진행이 복원되는지, iOS Safari와 실물 Android 기기에서의 성능은 별도 확인이 필요합니다.

테스트는 Playwright 가상 시간으로 requestAnimationFrame까지 순차 실행합니다. 게임을 순간이동시키거나 타이머를 직접 바꿔 통과시키지 않습니다.

## 아직 검증하지 않은 항목

실물 터치 기기의 조작감, Safari·Firefox, 저사양 GPU의 프레임률, 장시간 플레이, 제3자 호스팅의 지속 가용성, 실제 이용자 난이도·완주율은 미검증입니다. 멀티터치 에뮬레이션은 실제 기기 테스트를 대신하지 않습니다.
